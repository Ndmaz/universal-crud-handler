# Documentation

This directory contains the technical documentation for `@universal-crud/next` v0.1.

## Documents

- [Architecture](./architecture.md) — system structure and request lifecycle.
- [Contracts](./contracts.md) — public TypeScript interfaces and behavioral contracts.
- [Core](./core.md) — purpose and implementation of the dispatcher, handler, errors, and responses.
- [Helpers](./helpers.md) — action resolution and protected-field sanitization.
- [Registry](./registry.md) — registry APIs and generated registry behavior.
- [Rate Limiting](./rate-limiting.md) — rate-limit contracts and the in-memory implementation.
- [Client](./client.md) — fetch client and TanStack Query hooks.
- [CLI](./cli.md) — registry generator behavior and usage.

The documentation describes the v0.1 implementation as it exists in the source tree. It intentionally avoids describing future compiler, adapter, plugin, or framework abstractions that are not part of this release.
